# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in FlashText Search, please report it privately rather than opening a public issue.

You can report vulnerabilities via:
- GitHub Security Advisories
- Direct contact with the maintainer

We appreciate your effort in keeping FlashText Search and its users safe!
